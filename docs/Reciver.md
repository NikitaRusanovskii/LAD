# Документация для классов Reciever и Remote

## Обзор

Данный код представляет собой реализацию процессора с системой команд для целочисленных и вещественных операций. Архитектура следует паттерну "Команда" (Command), где `Reciever` является абстрактным интерфейсом, а `Remote` - конкретной реализацией процессора.

## Класс Reciever

### Назначение
Абстрактный базовый класс, определяющий интерфейс для всех поддерживаемых команд процессора.

### Методы
Все методы являются чисто виртуальными (абстрактными):

- **Арифметические операции:**
  - `ADD()`, `SUB()`, `MUL()`, `DIV()` - целочисленные операции
  - `FADD()`, `FSUB()`, `FMUL()`, `FDIV()` - операции с плавающей точкой
  - `INC()`, `DEC()` - инкремент и декремент

- **Логические операции:**
  - `AND()`, `OR()`, `NOT()`, `XOR()`

- **Операции сдвига:**
  - `SHL()`, `SHR()` - сдвиг влево/вправо

- **Операции сравнения и переходов:**
  - `CMP()` - сравнение
  - `JMP()` - безусловный переход
  - `JE()`, `JNE()`, `JL()`, `JLE()`, `JG()`, `JGE()` - условные переходы

- **Операции с памятью:**
  - `LD()`, `ST()` - загрузка/сохранение
  - `MOV()` - перемещение данных

- **Служебные:**
  - `NOP()` - операция без действия

## Класс Remote

### Назначение
Конкретная реализация процессора, наследуемая от `Reciever`. Обрабатывает команды, управляет регистрами и взаимодействует с памятью.

### Поля класса

- `current_instruction` - текущая выполняемая инструкция
- `registers` - массив целочисленных регистров (32 регистра)
- `registers_f` - массив регистров с плавающей точкой (64 регистра)
- `memory` - указатель на объект памяти
- `grid` - указатель на сетку команд
- `flag` - флаг состояния для условных переходов

### Макросы

- `REG(x)` - доступ к целочисленному регистру по индексу из команды
- `REGF(x)` - доступ к регистру с плавающей точкой
- `MEMR(x)` - чтение из памяти по вычисленному адресу
- `MEMW(x, v)` - запись значения в память по вычисленному адресу

### Основные методы

#### Конструктор и деструктор
- `Remote(Grid* _grid, Memory* _memory)` - инициализирует регистры и устанавливает связи
- `~Remote()` - освобождает память регистров

#### Вспомогательные методы
- `digit_getter(string s)` - извлекает числа из строки
- `jmp_address_detection(string token)` - определяет тип адреса перехода (+/-)
- `ld_st_address_converter(string s)` - преобразует строку адреса в числовой адрес
- `getRegisters()` - возвращает указатель на регистры
- `getCurrInst()` - возвращает ссылку на текущую инструкцию

#### Реализации команд

**Арифметические операции:**
- Выполняют соответствующие математические операции над регистрами
- Проверяют деление на ноль

**Логические операции:**
- Реализуют побитовые логические операции

**Операции сдвига:**
- Выполняют битовые сдвиги с проверкой границ

**Операции сравнения и переходов:**
- `CMP()` - устанавливает флаг на основе сравнения регистров
- Условные переходы проверяют флаг и изменяют `current_instruction`

**Операции с памятью:**
- `LD()` - загрузка данных из памяти в регистр
- `ST()` - сохранение данных из регистра в память
- `MOV()` - копирование между регистрами

**Обработка адресов:**
Поддерживаются различные форматы адресации:
- `reg+reg`, `const+reg`, `reg+const`, `const`, `reg`

## Особенности реализации

1. **Разделение типов данных:** отдельные регистры для целых чисел и чисел с плавающей точкой
2. **Обработка ошибок:** проверка деления на ноль, проверка границ сдвига
3. **Гибкая адресация:** поддержка различных способов вычисления адресов памяти
4. **Система флагов:** для реализации условных переходов

## Ограничения

- Фиксированное количество регистров (32 целочисленных, 64 с плавающей точкой)
- Проверка типов при операциях с памятью
- Обработка специальных случаев (деление на ноль, сдвиг за границы)
