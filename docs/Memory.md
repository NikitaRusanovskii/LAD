# Документация для класса Memory

## Обзор

Класс `Memory` представляет собой реализацию памяти с адресацией для хранения значений разных типов (int и double). Память организована как коллекция пар "адрес-значение" с отслеживанием типов данных.

## Структура данных

### Приватные поля:
- `vector<pair<int, double>> memory` - хранит пары (адрес, значение)
- `vector<bool> type_indicators` - флаги типов данных (true = double, false = int)

## Конструкторы

- `Memory()` - конструктор по умолчанию
- `Memory(const Memory& mem)` - конструктор копирования

## Публичные методы

### Управление типами данных
- `vector<bool> getTypes()` - возвращает вектор флагов типов данных

### Добавление данных
- `void add(const int address, const double value)` - добавляет значение типа double по указанному адресу
- `void add(const int address, const int value)` - добавляет значение типа int по указанному адресу

### Изменение данных
- `void store(const int address, const double value)` - сохраняет значение типа double по существующему адресу
- `void store(const int address, const int value)` - сохраняет значение типа int по существующему адресу

### Чтение и проверка
- `const double& operator[](const int address) const` - оператор индексации для чтения значений
- `bool contains(const int& address) const` - проверяет существование адреса в памяти

## Дружественные функции

- `ostream& operator<<(ostream& ostr, const Memory& mem)` - оператор вывода для отображения содержимого памяти

## Особенности реализации

### Хранение данных:
- Все значения хранятся как `double` для унификации
- Тип исходных данных отслеживается в отдельном векторе `type_indicators`

### Обработка ошибок:
- Методы `store()` выбрасывают исключения при попытке записи в несуществующий адрес
- Проверяется соответствие типа данных при операции записи

### Производительность:
- Поиск осуществляется линейным обходом (O(n)), что может быть неэффективно для больших объемов данных
- Используется `vector::emplace_back` для эффективного добавления элементов

## Пример использования

```cpp
Memory mem;
mem.add(0, 3.14);    // Добавляем double по адресу 0
mem.add(1, 42);      // Добавляем int по адресу 1

cout << mem[0];      // Читаем значение по адресу 0
mem.store(0, 2.71);  // Изменяем значение по адресу 0

cout << mem;         // Выводим все содержимое памяти
