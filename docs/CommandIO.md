# Документация для классов Command и SimpleCommand

## Обзор

Данный код реализует паттерн "Команда" (Command pattern) на C++. Паттерн инкапсулирует запрос в виде объекта, позволяя параметризовать клиентов с различными запросами, организовывать очередь запросов или поддерживать отмену операций.

## Классы

### Command (Абстрактный базовый класс)

Базовый абстрактный класс для всех команд в системе.

#### Защищенные поля:
- `Reciever* reciever` - указатель на объект-получатель, который будет выполнять фактическую работу

#### Публичные методы:
- `Command(Reciever* _reciever)` - конструктор, принимающий указатель на получателя
- `virtual ~Command()` - виртуальный деструктор для обеспечения корректного удаления производных классов
- `virtual void execute() = 0` - чисто виртуальный метод для выполнения команды (должен быть реализован в производных классах)

### SimpleCommand (Конкретная реализация команды)

Конкретная реализация команды, которая выполняет определенный метод получателя.

#### Приватные поля:
- `void(Reciever::* instruction)()` - указатель на метод класса Reciever, который будет выполнен

#### Публичные методы:
- `SimpleCommand(Reciever* r, void(Reciever::* _instruction)())` - конструктор, принимающий получателя и указатель на метод для выполнения
- `~SimpleCommand() = default` - деструктор по умолчанию
- `virtual void execute()` - реализация метода выполнения команды

## Принцип работы

1. **Command** создается с конкретным получателем (`Reciever`)
2. **SimpleCommand** дополнительно принимает указатель на конкретный метод получателя
3. При вызове `execute()` команда делегирует выполнение соответствующему методу получателя

## Пример использования

```cpp
Reciever* receiver = new Reciever();
Command* cmd = new SimpleCommand(receiver, &Reciever::someMethod);
cmd->execute(); // Вызывает receiver->someMethod()
