# Документация для класса Grid

## Обзор

`Grid` - это класс для разбора и валидации ассемблерного кода. Класс преобразует входную строку с ассемблерными инструкциями в структурированную сетку (grid) токенов после проверки синтаксиса с помощью регулярных выражений.

## Назначение

- Разбор ассемблерного кода на отдельные инструкции
- Валидация синтаксиса инструкций с использованием `RegularStorage`
- Преобразование кода в нижний регистр
- Структурированное хранение разобранных инструкций
- Предоставление безопасного доступа к разобранным данным
- Обработка ошибок парсинга с информативными сообщениями

## Структура класса

### Приватные поля

- `s` - исходная строка с ассемблерным кодом
- `size` - количество разобранных инструкций
- `grid` - двумерный вектор для хранения разобранных инструкций (сетка токенов)
- `keywords` - массив ключевых слов ассемблера

### Публичные методы

- `Grid(string _s)` - конструктор, принимающий строку с кодом
- `splitByInstructionsNames()` - разделение кода на инструкции
- `gridCreator()` - создание сетки токенов
- `to_lower_letter()` - преобразование в нижний регистр
- `getSize()` - получение количества инструкций
- `operator[]` - доступ к инструкции по индексу
- `at()` - безопасный доступ с проверкой границ
- `contains()` - проверка существования инструкции

## Ключевые слова

Класс поддерживает 28 ассемблерных инструкций:

- **Операции с памятью**: `ld`, `st`, `mov`
- **Целочисленная арифметика**: `add`, `sub`, `mul`, `div`
- **Арифметика с плавающей точкой**: `fadd`, `fsub`, `fmul`, `fdiv`
- **Логические операции**: `and`, `or`, `xor`, `not`
- **Битовые операции**: `shl`, `shr`
- **Инкремент/декремент**: `inc`, `dec`
- **Сравнение**: `cmp`
- **Операции перехода**: `jmp`, `je`, `jne`, `jl`, `jle`, `jg`, `jge`

**Примечание**: В массиве keywords есть опечатка - отсутствует запятая между `"jne"` и `"jl"`.

## Алгоритм работы

### 1. Инициализация
- Сохранение входной строки
- Инициализация списка ключевых слов
- Преобразование всей строки в нижний регистр
- Обработка исключений при создании сетки

### 2. Разделение на инструкции (`splitByInstructionsNames`)

Алгоритм использует оптимизированный подход:

- **Предварительная фильтрация** по первому символу для быстрого отсева
- **Проверка полного совпадения** только с релевантными ключевыми словами
- **Проверка границ слов** - гарантия, что ключевое слово не является частью другого слова

**Пример работы:**

Исходная строка: "ld [1008] r1 add r1 r2"
Результат: ["ld [1008] r1", "add r1 r2"]


### 3. Создание сетки (`gridCreator`)

- Для каждой инструкции проверяется соответствие регулярным выражениям из `RegularStorage`
- При успешном совпадении извлекаются группы захвата (операнды)
- Инструкция добавляется в сетку как вектор строк-токенов
- При несоответствии генерируется исключение с указанием строки ошибки

### 4. Обработка ошибок

- Конструктор перехватывает исключения `runtime_error` из `gridCreator`
- При ошибке выводит сообщение и завершает программу с кодом `EXIT_FAILURE`
- Сообщения об ошибках включают номер строки (в формате адреса памяти: i * 4)

## Методы доступа

### `operator[](int ind)`
- Прямой доступ к инструкции по индексу
- Без проверки границ (для производительности)

### `at(int ind)`
- Безопасный доступ с проверкой границ
- Генерирует `out_of_range` при неверном индексе

### `contains(const int& ind)`
- Проверяет существование инструкции с заданным индексом

## Перегрузка операторов вывода

### `operator<<(ostream&, const vector<string>)`
- Вывод вектора строк через пробел
- Добавляет перевод строки

### `operator<<(ostream&, const Grid&)`
- Форматированный вывод всей сетки
- Адреса инструкций выводятся в шестнадцатеричном формате с ведущими нулями
- Формат: "адрес инструкция_токены"

## Особенности реализации

### Эффективность
- Предварительная фильтрация по первому символу ускоряет разбор
- Использование `emplace_back` для избежания копирования
- Резервирование памяти для вектора grid

### Безопасность
- Преобразование символов с использованием `static_cast<unsigned char>` для корректной работы `tolower`
- Проверка границ при доступе через `at()`
- Обработка исключений в конструкторе

### Обработка ошибок
- Информативные сообщения об ошибках с указанием номера строки
- Завершение программы при критических ошибках парсинга
- Защита от доступа к несуществующим инструкциям
