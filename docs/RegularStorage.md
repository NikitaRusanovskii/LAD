# Документация для класса RegularStorage

## Обзор

`RegularStorage` - это класс, реализующий шаблон проектирования **Одиночка (Singleton)**, который предоставляет централизованное хранилище регулярных выражений для парсинга ассемблерных инструкций и операций с памятью.

## Назначение

Класс предназначен для:
- Хранения предварительно скомпилированных регулярных выражений
- Парсинга инструкций ассемблера
- Обработки операций с памятью
- Обеспечения единого доступа к регулярным выражениям во всем приложении

## Структура класса

### Приватные статические поля

- `_instance` - указатель на единственный экземпляр класса
- `instructions_storage` - вектор регулярных выражений для инструкций
- `memory_storage` - вектор регулярных выражений для операций с памятью

### Публичные методы

- `Instance()` - получение экземпляра класса (реализация Singleton)
- `getInstructionsStorage()` - получение хранилища инструкций
- `getMemoryStorage()` - получение хранилища операций с памятью

## Регулярные выражения

### Инструкции (instructions_storage)

1. **DIV операция** - деление с 4 регистрами
2. **Операции с плавающей точкой** - fadd, fsub, fmul, fdiv
3. **Базовые арифметические операции** - add, sub, mul, and, or, xor, shl, shr
4. **Логическая операция NOT**
5. **Операции сравнения** - cmp (целочисленные и с плавающей точкой)
6. **Инкремент/декремент** - inc, dec
7. **Операции перехода** - jmp, je, jge, jl, jg, jle, jne
8. **Операции с памятью** - ld, st, mov (целочисленные и с плавающей точкой)

### Операции с памятью (memory_storage)

1. **Регистр + Регистр** - `[Rx ± Ry]`
2. **Константа + Регистр** - `[const ± Rx]`
3. **Регистр + Константа** - `[Rx ± const]`
4. **Только константа** - `[const]`
5. **Только регистр** - `[Rx]`

## Особенности реализации

### Шаблон Одиночка
- Конструктор защищен (`protected`)
- Единый доступ через статический метод `Instance()`
- Ленивая инициализация экземпляра

### Статические векторы
- Регулярные выражения инициализируются при загрузке программы
- Доступ только для чтения через константные ссылки
- Исключается копирование данных при возврате

## Использование

```cpp
// Получение экземпляра
RegularStorage* storage = RegularStorage::Instance();

// Получение регулярных выражений
